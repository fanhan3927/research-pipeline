# 闪电三问话术卡

**适用场景**：NDA 签署之前，电话 / 微信 / 首次见面，口头问完即可，不形成书面文件、不要求对方书面确认、不留痕给对方。
**目的**：判断"值不值得往下推"，不是尽调，也不是信息采集表的替代品——它只解决一个问题：在还没有 LP 确认意向、对方也不愿在无回报预期下签 NDA 的僵局里，用最小的信息量先破局。
**配套工具**：《硬科技项目速筛卡》（15分钟十问，pre-NDA 书面版，用于闪电三问之后仍需要留痕/交接给同事时）、《硬科技项目信息采集表》（NDA 之后的完整版）。三者是递进关系，不要跳级使用，也不要因为有了后两者就不用这个——闪电三问的价值恰恰在于它足够轻，可以在对方还没决定要不要认真对待你之前就问完。

---

## 使用前提

- 只在真正的首次接触时用，问完之后原则上不再重复问同一批问题
- 只口头问，不发文字版问题清单给对方——发清单本身就会被当成"正式材料请求"，触发 NDA 反射
- 答案不需要精确数字，量级/方向性描述即可，越具体的数字反而越会让对方警觉

---

## 三问

### 问一　进度 + 财务量级

> "公司现在到哪个阶段——还在打样，还是已经有客户在批量用？大概什么营收量级（百万 / 千万 / 亿），亏钱还是打平？"

对应判断：业务进度是否够得上继续聊（红线 R1 粗筛）+ 营收/盈亏量级是否达到定级门槛（A/B 级门槛①②的粗筛）

### 问二　交易结构 + 估值方向

> "这次是增资还是老股？这个价格比上一轮是涨了还是跌了？有没有回购兜底？"

对应判断：估值倒挂风险（红色事项 Y3）、回购安排（红色事项 Y2）、交易结构类型——这三项直接决定后续能匹配哪类资金方

### 问三　时效 + 竞争态势

> "什么时候希望 close？现在还有没有别的机构在看，进展到哪一步？"

对应判断：时间窗口能否匹配到合适的资金方（时间越紧，能接的资金方类型越少）、是否需要抢时间推进

---

## 明确不问（留到 NDA 之后）

- 具体客户名单、具体合同金额
- 具体专利号、具体技术参数
- 具体财务报表数字（三问只要量级，不要精确值）
- 实控人个人情况、股权结构细节

---

## 三问之后：怎么破局"先有鸡还是先有蛋"

```
闪电三问（口头，不留文件）
   ↓
内部判断：值不值得往下推？
   ↓ 值得
把三问答案剥成一段匿名一句话 teaser（见下方模板）——
不含公司名、不含具体数字、不含客户名
   ↓
拿这段话去跟 1-2 个熟悉的 LP 口头探温度
   ↓ 有兴趣
回头跟项目方说："我们已经有资方在看，需要签 NDA 才能往下推"
   ↓
签 NDA → 用《信息采集表》或直接访谈拿完整信息
   （优先用访谈记录代替让对方填表——同样的信息，体验完全不同，
   访谈记录由本方整理成采集表格式留痕，不是把表格甩给对方要求填）
```

这段流程的关键：**先用最轻的信息换到 LP 的真实兴趣信号，再拿这个信号去换项目方的 NDA**，而不是反过来先伸手要信息。NDA 的说服力也从"我们需要材料"变成"我们已经有资方在等你回复"，谈判位置更强。

## 匿名一句话 Teaser 模板

用于向 LP 口头/微信探温度，**不含**公司名称、具体客户名称、具体财务数字、具体估值数字、任何商务条款信息。只用问一到问三答案里的**量级和方向**。

```
[赛道] 领域的设备/技术公司，成立于 [年份]，团队背景 [一句话，如"来自全球头部同类厂商"]。
业务进展：[阶段量级，如"已进入小批量至部分产品线批量交付阶段，头部客户复购中"]，
[财务量级，如"2025年营收千万级，尚未盈利"]。
本次为 [增资/老股]，估值 [高于/持平/低于] 上一轮，[有/无] 回购安排。
期望 [时间窗口] 完成，[如有：一级市场关注度较高/多方在推进]。
是否有兴趣了解更多？
```

填完之后过一遍关键词兜底扫描（复用投资人材料包的检查脚本）：

```
python scripts/check_external_safe.py --input <teaser文件路径> --project-dir <project_dir>
```
